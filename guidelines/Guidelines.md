## MBK.GLOBAL Design DNA

**Stance:** botanical field-notes — an editorial, quietly technical agency identity. The interface should feel like a considered studio journal, not a SaaS template: warm paper ground, forest ink, pressed-leaf greens and a restrained ochre signal.

**Type:** Fraunces is reserved for editorial moments and decisive statements; Plus Jakarta Sans carries all product and body copy; DM Mono identifies systems, labels, locations and data. Display type uses close-but-breathing tracking; mono labels are uppercase and generously tracked.

**Colour:** cream is the working canvas; deep forest is ink and night-field; green is action; pale botanical green is the secondary surface; muted gold marks sequence, offers and important joins. Never use a generic rainbow gradient.

**Layout:** a 12-column, paper-like editorial grid with long horizontal rules, asymmetrical pairings and generous vertical intervals. Cards should be square-to-lightly-rounded, structural and quiet. Use 1px botanical-ink dividers and gold only for orientation.

**Motion:** motion has a job. Text and image reveals use a soft 600–900ms rise; botanical particles drift at low opacity; hover states provide a 150–300ms physical response. Respect reduced motion and pause continuous movement when a user asks for it.

**Responsive:** on narrow screens, preserve reading order and reduce animation density. Navigation becomes a clear stacked panel; grids become a sequence, never compressed columns; type steps down through clamp values rather than abrupt scaling.

**Accessibility:** maintain AA text contrast, visible keyboard focus, semantic landmarks and labelled controls. Motion and 3D must have static/reduced-motion fallbacks.

## Button
The Button component is a fundamental interactive element in our design system, designed to trigger actions or navigate
users through the application. It provides visual feedback and clear affordances to enhance user experience.

### Usage
Buttons should be used for important actions that users need to take, such as form submissions, confirming choices,
or initiating processes. They communicate interactivity and should have clear, action-oriented labels.

### Variants
* Primary Button
  * Purpose : Used for the main action in a section or page
  * Visual Style : Bold, filled with the primary brand color
  * Usage : One primary button per section to guide users toward the most important action
* Secondary Button
  * Purpose : Used for alternative or supporting actions
  * Visual Style : Outlined with the primary color, transparent background
  * Usage : Can appear alongside a primary button for less important actions
* Tertiary Button
  * Purpose : Used for the least important actions
  * Visual Style : Text-only with no border, using primary color
  * Usage : For actions that should be available but not emphasized
