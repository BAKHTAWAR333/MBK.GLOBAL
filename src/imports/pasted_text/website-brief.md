Create a world-class, highly professional, modern, responsive, and visually impressive website. Do NOT create a basic template or generic AI-looking website. The final result should feel like it was designed and developed by an expert team of senior UI/UX designers, motion designers, creative developers, and frontend engineers.

CORE REQUIREMENT

Use ALL of the following skills and technologies to make the website significantly better, more professional, interactive, responsive, polished, and visually memorable:

1. Design DNA

Use Design DNA to reverse-engineer and structure the visual identity of the website.

https://github.com/zanwei/design-dna

Use it for:

- Design token extraction and organization
- Typography system
- Color palette
- Spacing system
- Layout analysis
- Visual hierarchy
- UI style
- Copy style
- Qualitative visual style
- Visual effects
- Consistent design language

Create a complete and consistent Design DNA before implementing the UI. Every component should follow the same visual identity.

2. Motion Design

Treat animation as a core part of the design, NOT as an afterthought.

Implement:

- Lottie animations
- SVG animations
- Timeline animations
- Keyframe animations
- Interactive states
- Hover animations
- Micro-interactions
- Loading animations
- Page transitions
- Scroll-based animations
- Animated UI elements
- JSON / dotLottie animation support where appropriate

Animations must feel smooth, intentional, premium, and professional. Avoid excessive or distracting animation.

3. GSAP

Use GSAP extensively wherever it improves the experience.

https://gsap.com/

Implement:

- GSAP timelines
- ScrollTrigger
- Text reveal effects
- Stagger animations
- Image reveal animations
- Section entrance animations
- Parallax effects
- Smooth transitions
- Interactive hover effects
- Page transition sequences
- React-compatible GSAP architecture

Use animation sequencing intelligently so the website feels cinematic and professionally art-directed.

4. Three.js

Use Three.js wherever a 3D experience can improve the website.

https://threejs.org/

Implement where appropriate:

- Interactive 3D scenes
- 3D objects
- Camera movement
- Lighting
- Depth effects
- Particle systems
- Interactive backgrounds
- Mouse-based 3D interaction
- Scroll-based 3D movement

The 3D experience should enhance the website instead of making it unnecessarily heavy.

5. RESPONSIVE DESIGN

The website must be fully responsive across:

- Mobile phones
- Tablets
- Laptops
- Desktop monitors
- Large screens

Do not simply shrink the desktop layout.

Create dedicated responsive behavior for:

- Navigation
- Typography
- Cards
- Grids
- Images
- Animations
- 3D scenes
- Buttons
- Spacing
- Sections

Make sure everything works perfectly on touch devices.

6. PROFESSIONAL UI/UX

Create a premium visual hierarchy with:

- Strong typography
- Perfect spacing
- Professional grids
- Clear navigation
- High-quality buttons
- Elegant cards
- Beautiful forms
- Consistent border radius
- Subtle shadows
- Depth
- Glass effects only where appropriate
- Sophisticated hover states
- Meaningful micro-interactions

Avoid:

- Generic AI gradients
- Overused glassmorphism
- Random animations
- Poor spacing
- Template-looking sections
- Excessive rounded cards
- Unnecessary effects

7. PERFORMANCE

Despite using advanced animations and 3D, the website must remain fast.

Optimize:

- Images
- SVGs
- Lottie files
- Three.js rendering
- GSAP animations
- Lazy loading
- Code splitting
- React components
- Asset loading

Respect reduced-motion preferences and provide graceful fallbacks for low-performance devices.

8. CODE QUALITY

Build the website using clean, scalable, production-ready architecture.

Use:

- React
- Modern JavaScript/TypeScript where appropriate
- Reusable components
- Modular architecture
- Clean folder structure
- Semantic HTML
- Accessible UI
- Maintainable CSS/Tailwind styling
- Proper responsive breakpoints

Do not put the entire website into one giant component.

9. INTERACTION DESIGN

Every important interactive element should have a meaningful state:

Default → Hover → Active → Focus → Loading → Success/Error where applicable.

Add subtle feedback so the interface feels alive and premium.

10. FINAL QUALITY BAR

The final website should look like a premium digital product created by a professional creative development studio.

Think:

Award-winning agency website

+ Premium SaaS product
+ Cinematic motion design
+ Interactive 3D experience
+ Professional UI/UX system

The final result should NOT look AI-generated.

Before finishing, review the entire website and improve:

- Visual consistency
- Typography
- Spacing
- Responsive behavior
- Animation timing
- Accessibility
- Performance
- Mobile experience
- Component consistency
- Overall visual polish

Use the Design DNA, Motion Design, Lottie, SVG Animation, GSAP, ScrollTrigger, and Three.js skills together intelligently to create a significantly better, more professional, responsive, interactive, and visually memorable website.

Do not merely add these technologies for the sake of mentioning them. Use each technology only where it provides a real improvement to the user experience.
